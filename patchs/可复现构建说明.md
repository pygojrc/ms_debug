# Frida 17.15.3 可复现构建说明

本目录以独立复现为目标，集中保存当前 Frida 17.15.3 patch 分支所需的补丁、脚本、依赖说明和验证说明。

## 目录内容

- `README.md`：每个补丁的作用、范围和迁移状态。
- `依赖信息.md`：复现所需工具、NDK、源码基线和构建产物位置。
- `apply_frida_17_15_3_patches.sh`：自动应用所有 17.15.3 补丁的脚本。
- `apply_production_cleanup_patches.sh`：在基础补丁之后移除生产版不需要的诊断/验证代码。
- `rollback/`：生产清理 rollback patch，目标是已经应用 `001..006` 的源码树。
- `*.patch`：相对 Frida `17.15.3` 及项目构建脚本的实际改动。

## 推荐复现步骤

在项目根目录执行：

```bash
bash patchs/apply_frida_17_15_3_patches.sh
FRIDA_TARGET=frida-server bash scripts/run_podman.sh
```

生产版推荐在构建前追加：

```bash
bash patchs/apply_production_cleanup_patches.sh
FRIDA_TARGET=frida-server bash scripts/run_podman.sh
```

`scripts/run_podman.sh` 默认使用 `localhost/ubuntu26:dev`，并挂载 `/data/opt/android-ndk-r29`。

## 补丁应用原则

这些 patch 的目标目录不同，不能直接用下面这种方式一次性应用：

```bash
git apply patchs/*.patch
```

必须使用 `patchs/apply_frida_17_15_3_patches.sh`，或按 `README.md` 中列出的目录逐个应用。
生产清理 patch 也必须通过 `patchs/apply_production_cleanup_patches.sh`，或按 `README.md` 中的 rollback 说明逐个应用到对应子仓库。
