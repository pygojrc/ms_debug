# 复现依赖信息

本文件记录 `patchs/` 复现当前 Frida 17.15.3 构建成果所需的外部条件。

## 本机工具

- 容器：`podman`
- JDK：`~/.jdks`
- Android SDK：`/home/ms/Android/Sdk`
- Android NDK r29：`/data/opt/android-ndk-r29`

当前构建脚本默认使用 `localhost/ubuntu26:dev`。脚本会检查 `ANDROID_NDK_ROOT/source.properties`，并要求主版本为 `29`。

## 源码基线

- Frida 主仓库 tag：`17.15.3`
- `frida-core` 基线提交：`9492205c6a968133dbd50f1fe0455e39a3e6fd70`
- `frida-gum` 基线提交：`befbceab8f9c4f5d4a5e939f675df5c669b44510`
- `glib` 基线提交：`92d65736b198c2cf131f691dd83db0b25f7b02d2`

## 构建入口

推荐命令：

```bash
bash patchs/apply_frida_17_15_3_patches.sh
FRIDA_TARGET=frida-server bash scripts/run_podman.sh
```

可选目标：

```bash
FRIDA_TARGET=frida-server bash scripts/run_podman.sh
FRIDA_TARGET=frida-inject bash scripts/run_podman.sh
FRIDA_TARGET=frida-gadget bash scripts/run_podman.sh
```

## 构建产物位置

- Meson 构建目录：`build/frida-android-arm64`
- 安装前缀：`build/install-android-arm64`
- 运行日志：`tmp/running.md`

## Android SDK 静态库修补

当前 Android 构建会链接 `frida/deps/sdk-android-arm64/lib/` 中的预构建静态库。为了让 `frida-server`、`frida-inject`、`frida-gadget` 都使用同一套线程名修补结果，构建脚本会在链接前临时修补：

- `libglib-2.0.a`
- `libgio-2.0.a`

构建结束后脚本会反向恢复这两个 `.a`，避免 `frida/deps` 长期处于本项目特定状态。
